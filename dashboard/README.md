# 📊 agentsh Mission Control Dashboard

Next.js frontend dashboard connecting to the `agentsh` control plane (`127.0.0.1:4439`) to display real-time run telemetry, active advisory policies, and cryptographic HMAC-SHA256 audit logs.

## 🚀 Getting Started

```bash
cd dashboard
npm install
NEXT_PUBLIC_STUNTDOUBLE_TOKEN=$STUNTDOUBLE_TOKEN npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view Mission Control.
